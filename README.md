# 🦷 Solis Dental Studio | Modern AI Oral Ecosystem

### **[Speculative Build By Purple Cove Labs]**

A high-fidelity, 3D-first digital experience designed for the intersection of biotechnology and fine art in Piantini, Santo Domingo. This build serves as a showcase for **Purple Cove Labs'** ability to blend high-end aesthetics with extreme clinical precision.

---

## **🌌 The Aesthetic Vision**
Solis Dental is not just a clinic; it is the **Obsidian Sanctuary**. The digital experience uses:
- **Cinematic Grain Textures**: For a high-art, tactile feel.
- **Glass-Obsidian Elements**: Premium frosted surfaces for UI components.
- **Precious Metal Accents**: Gold and Emerald color palettes reflecting luxury and clinical excellence.
- **3D Particles**: Real-time React Three Fiber particle systems (Gold Dust) for ambient immersion.

---

## **🧬 Technical Architecture**
Built on a modern, high-performance stack for absolute responsiveness and cinematic motion:

- **Next.js 16 (App Router)**: The framework for high-speed, localizable oral ecosystems.
- **TypeScript**: Ensuring type-safe surgical precision in the codebase.
- **Framer Motion**: Powering fluid, scroll-driven reveals and route transitions.
- **React Three Fiber (Three.js)**: For the **Precision Grid Visualizer** and interactive atmospheric backgrounds.
- **Tailwind CSS**: A fully customized design system with fluid typography and spatial grids.
- **Custom Localization Context**: On-the-fly toggling between English and **Dominican Spanish**.

---

## **📂 Core Clinical Features**
- **Precision Grid Visualizer**: A 3D interactive grid representing our zero-error clinical tolerance.
- **Clinical Before/After Slider**: High-fidelity visualization of patient outcomes.
- **Interactive Timeline**: An animated, swipable journey through the Solis legacy (2021–2026).
- **Responsive Dynamic Navbar**: A persistent, pill-based navigation system with vertical scroll signals.

---

## **🚀 Build & Deployment**
Designed for the modern web with performance and SEO at its core.

npm install

npm run dev

# Build for production
npm run build

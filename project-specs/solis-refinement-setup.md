# Solis Dental Hub Refinement Spec

## Context
A cinematic dental studio project in Santo Domingo (Piantini) built by Purple Cove Labs (PCL). The site exists but lacks "Premium Agency" polish.

## Objective
Implement 5 key fine-tuning layers to elevate the user experience to "Oryn" (Agency) standards.

### 1. High-Fidelity Asset Replacement
Replace all placeholder images with bespoke, photorealistic luxury dental visuals matching the Charcoal, Emerald, and Gold palette.
- Hero Image: Macro clinical luxury.
- Gallery Images: Specific case thumbnails for Veneers, Invisalign, and Bio-Implants.

### 2. Immersive Motion & Interaction
Implement high-end interface behaviors to boost perceived quality.
- Custom Cursor Engine: Reactive gold/emerald interaction.
- Smooth Scrolling: Implementation of Lenis or similar momentum-based scroll.
- Magnetic Timeline: Refine the about-page carousel with snapping and elastic drag.

### 3. Clinical Proof Interactive Suite
Build an interactive before-after comparison slider to demonstrate "Scientific Art" results.

### 4. Advanced Global UI Polish
- AnimatePresence: Smooth cross-fades and slide transitions between all pages.
- Depth & Texture: Subtle grainy noise overlay and background depth (gold dust).
- Sticky CTA: Universal minimal booking trigger.

### 5. Functional Refinement
- Cal.com Stylized Embed: Real-world booking logic stylized for PCL/Solis.
- Dynamic Navbar: Scroll-direction aware navigation hub.

## Constraints
- Palette: Charcoal, Emerald, Gold.
- Tone: Professional, Scientific, Boutique, Premium.
- Tech: Next.js, Framer Motion, Tailwind.
- No em dashes.
